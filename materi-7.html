Apa itu Sistem Komputer?

Sistem Komputer adalah kumpulan perangkat-perangkat komputer yang saling berhubungan dan berinteraksi satu sama lain untuk mengolah data sehingga menghasilkan informasi yang berguna bagi pengguna.

3 Elemen Utama Sistem Komputer:

1. Hardware

Perangkat keras yang memiliki bentuk fisik nyata dan dapat disentuh (contoh: Keyboard, CPU, Monitor).

2. Software

Perangkat lunak berupa program/instruksi tidak berwujud fisik (contoh: Windows, MS Word, Web Browser).

3. Brainware

Pengguna atau manusia yang mengoperasikan dan memberi perintah pada sistem komputer.

MINI CHALLENGE: Kelompokkan Elemen!

LEVEL 2 dari 3
Perangkat Input

Memasukkan data atau perintah dari luar ke dalam komputer.

  • Keyboard: Mengetik teks & angka
  • Mouse: Menggerakkan kursor
  • Scanner & Webcam: Mengambil foto/dokumen
  • Mikrofon: Memasukkan suara
Perangkat Proses

Mengolah data yang dimasukkan oleh perangkat input.

  • CPU: Otak pemroses data utama
  • RAM: Memori penyimpanan sementara
  • Motherboard: Papan sirkuit penghubung
Perangkat Output

Menampilkan hasil pengolahan data kepada pengguna.

  • Monitor: Menampilkan visual/gambar
  • Printer: Mencetak hasil ke kertas
  • Speaker: Mengeluarkan suara
  • Proyektor: Memancarkan layar besar

Perangkat Penyimpanan (Storage)

Menyimpan data dan berkas secara permanen (non-volatile) maupun sementara.

HDD & SSD: Penyimpanan utama internal PC. SSD jauh lebih cepat dari HDD.
Flashdisk & Memory Card: Penyimpanan portabel yang mudah dibawa.
Cloud Storage: Penyimpanan berbasis internet (Google Drive, OneDrive).

Perangkat Lunak (Software)

Instruksi terprogram yang menjalankan tugas spesifik di komputer.

Sistem Operasi (OS): Mengelola hardware dan software dasar.
Contoh: Windows, macOS, Linux, Android.
Software Aplikasi: Membantu pekerjaan pengguna secara spesifik.
Contoh: MS Word, Excel, Chrome, Photoshop.
