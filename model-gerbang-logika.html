Panduan Praktikum

  1. Tekan sakelar POWER ON/OFF di pojok kiri atas modul 3D.
  2. Klik mode Pasang Kabel. Klik pin asal (contoh: Input 1), lalu klik pin tujuan (contoh: Pin Gate AND Input A).
  3. Hubungkan output Gate ke salah satu LED Output (LED 1 - LED 7).
  4. Klik sakelar input untuk mengubah status biner (0 ↔ 1).
  5. Kabel akan otomatis menyala Hijau saat bertegangan logika 1!
